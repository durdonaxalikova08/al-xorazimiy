dir -> joriy papkadagi fayl va papkalr to'yxatini ko'rsatish.
nano [filename. filetype] -> fayil yaratish yoki ko'rish.
git clone [projekt_url] -> loyihani klon qilish.
git add . -> GITga yangi o'zgarishni qo'shish.
git commit -m "[bajarilgan ishga qisqa tavsif]" -> GITga qo'shilganlarga COMMIT berish.
git push -u origin main -> Barcha COMMITlarni (barcha bajarilgan ishlarni) git (github,gitlab)ga saqlash.
